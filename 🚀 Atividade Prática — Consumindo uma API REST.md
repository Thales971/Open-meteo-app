# Guia 1

# **🚀 Atividade Prática — Consumindo uma API REST**

## **Objetivo**

Cada aluno (ou dupla) deverá escolher **uma API pública** e desenvolver um aplicativo em **React Native (Expo)** que consuma seus dados.

O objetivo é praticar:

* Consumo de APIs REST
* Requisições HTTP com `fetch()`
* Programação assíncrona (`async/await`)
* Manipulação de JSON
* Componentização
* Exibição de listas utilizando `FlatList`
* Navegação entre telas (opcional)

---

# **APIs disponíveis**

Escolha **uma** das APIs abaixo:

| API | Tema |
| ----- | ----- |
| JSONPlaceholder | Usuários, posts |
| DummyJSON | Produtos |
| PokeAPI | Pokémon |
| Random User | Pessoas |
| Dog API | Cachorros |
| Cat Fact | Curiosidades |
| REST Countries | Países |
| Rick and Morty | Personagens |
| Open Meteo | Clima |
| Advice Slip | Conselhos |

---

# **Requisitos obrigatórios**

O aplicativo deverá possuir:

* ✅ **Tela inicial**
* ✅ **Buscar informações** da API
* ✅ Exibir os dados em uma lista (**`FlatList`**)
* ✅ Utilizar **`fetch()`**
* ✅ Utilizar **`async/await`**
* ✅ Exibir indicador de carregamento (**`ActivityIndicator`**)
* ✅ **Tratar erros** de conexão
* ✅ **Interface organizada**

---

# **Requisitos extras (+ bônus)**

Escolha um ou mais desafios para destacar seu projeto:

* ⭐ **Campo de pesquisa**
